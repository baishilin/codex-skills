# 双重机器学习（DML）实证分析 · 详细工作流

> 本文件是 dml-empirical skill 的详细工作流与全局规则；入口见 SKILL.md，输入清单见 references/inputs.md，诊断与敏感性见 references/diagnostics.md。

## 全局规则（完整版，每一轮都生效）

1. **软件环境**：Stata 用 `ddml`（+`pystacked`/`lassocv`）经 stata skill 的本地 MCP；缺包用 `stata_install_package`。
   Python 替身用 `doubleml` + `scikit-learn`。在 do 文件/脚本与交付说明里记录软件与包版本。
2. **必须真跑（无论哪个引擎）**：每步先写代码再执行；报错先自行定位修正，最多重试 3 次；
   最终给出可复现的完整脚本与 log 关键片段。所有报告数字必须来自真实输出，禁止编造、抄错或“合理估计”。
   固定随机种子：Stata `set seed {种子}`；Python `np.random.seed({种子})` + 每个学习器 `random_state={种子}`；
   交叉拟合的分割变量（folds var）必须固定并在脚本中保存，保证可复现。
3. **数据预处理**：正确读入（import/use 或 pandas.read_*）、核对变量类型（destring/encode 或 astype/categorical）、
   `xtset {个体} {时间}`（Python 用 MultiIndex 设面板）并报告是否平衡、贴标签、报告关键变量缺失值及处理方式（删失/插值/多重插补须注明方法）。
   缩尾只对**连续 Y 与连续 X**，默认双侧 1%（Stata `winsor2 {Y} {X}, replace cuts(1 99)`，Python `scipy.stats.mstats.winsorize`）。
   **不缩尾 D**（0-1/政策虚拟变量绝不缩尾；连续强度变量确需缩尾须说明理由）。滞后一期：若设定要求 Y 或 X 滞后，须明确报告
   （如 Y_{t+1} 对应 2011–2020、解释变量 2010–2019），并说明原因（避免反向因果/政策效应滞后）。同时输出：①样本筛选流程图；②变量定义表。
   **若 Y 为复合指数**：先写清测算方法（指标体系维度、标准化方式、权重：主观 AHP/客观熵权/主客观组合赋权、DEA、PCA、TOPSIS），
   并在稳健性中更换测算口径验证结论不依赖具体测算方法。
4. **处置变量与结局变量类型**：按 D×Y 类型选模型与学习器——D 二元→辅助回归 m(X) 用分类器（logit/随机森林分类），
   D 连续→回归器，D 多值→多分类器；Y 连续→主回归 g(X) 用回归器（PLR/IRM），Y 二元→用逻辑部分线性（LPQ/logit）或 LPM，并报告边际效应口径。
   特征工程：多项式（二次项）、交互项、log 变换按需构造；lasso/神经网络对尺度敏感时先标准化（树模型不需要）。
5. **固定效应处理（DML 特有）**：DML 中 FE 有三种处理方式，必须选一种并注明：
   (a) 把个体/时间虚拟变量作为 X 的一部分交给学习器（最常见，lasso/随机森林均可吸收）；
   (b) 先做组内去均值（within-demeaning）或按 FE 残差化，再对残差跑 DML；
   (c) 只控制时间 FE + 其他层级 FE 的组合。选择时要保证**处置效应识别所用 X 的维度与 FE 吸收充分**，并在表注写明。
6. **学习器与超参数**：主回归 g(X) 与辅助回归 m(X) 可各用一个学习器；默认给一组基准学习器（lasso CV / 随机森林 / 梯度提升），并在稳健性中更换。
   **嵌套交叉拟合**：若对学习器做超参数调优，必须在 DML 交叉拟合的每个折内单独调参，防止信息泄漏；未做则如实说明。
   报告每个 nuisance 模型的折外预测性能（回归用 R²/MSE，分类用 AUC/准确率），论证学习器选择合理。
7. **交叉拟合与样本分割**：默认 K=5 折交叉拟合（等价论文常用“1∶4 分割”），可设 reps 多次重复以降低随机性；
   稳健性中改变 K（如 2、10）或分割比例。**必须报告 K 与 reps**；reps 汇总口径为**各分割估计的中位数**（DoubleML 默认），
   并报告分割间分散度（IQR），不要简单取平均。
8. **信息泄漏防护（硬性）**：ĝ 与 m̂ 必须用**未包含该观测**的折来预测该观测的残差；折内调参、折外预测；严禁全样本训练后再对全样本预测。
   `ddml` 与 `DoubleML` 内部自动完成交叉拟合，不要手工“先全样本 fit 再 predict”。违反此条将导致标准误严重偏小、假显著。
   **标准化、缺失值插补、类别编码也必须在每个折内学习参数并应用到折外**，严禁用全样本均值/分位预先标准化或插补（同样是信息泄漏）。
9. **标准误**：DML 标准误基于正交化得分 ψ̂ 的样本方差（√n 渐近）；聚类稳健标准误聚类层级**必须 ≥ D 的变异/处理发生层级**
   （地区/行业政策不能聚到个体层面）。聚类数 < 40~50 **必须补 wild cluster bootstrap** p 值（Python `wildboottest`、Stata `boottest`）；
   面板需双向聚类时用 `DoubleMLClusterData`（cluster_cols=[个体, 时间]）。详见 `references/diagnostics.md` D5。
10. **显著性与经济显著性**：`*** p<0.01`，`** p<0.05`，`* p<0.1`；括号报标准误（或 t/z 值）保留两位小数；给 95% 置信区间。
    另报经济显著性：D 一个标准差（基于全样本或处理前口径）带来的 Y 变化及其占 Y 均值/标准差的百分比。
11. **表格（三线表，硬性）**：所有结果表必须按**论文期刊三线表格式**严格输出为**可复制文本**（顶线粗、栏目线细、底线粗、无竖线、
    无行间横线），完整规范见 `references/tables.md`。每模型一列；表头写清被解释变量；表注写明控制变量（一次项/二次项）、
    固定效应、学习器、交叉拟合折数、标准误类型与聚类层级、显著性水平；每列报 N（DML 无 R² 时改报 θ̂、标准误与 95% CI，
    并注明）。**禁止以 PNG 图片、带竖线的 Word 网格表或未格式化 CSV 作为结果表交付；结果表必须是可复制文本。**
    Stata 用 `ddml` 自带输出整理（`esttab`/`estout` 的 booktabs 选项，或 `stata_etable` 原生表）；Python 用 DataFrame 导出 CSV，再生成 Markdown/LaTeX 三线表与 Word 原生 booktabs 表；图片仅用于真正的图。
12. **每步三段式输出**：①代码 → ②三线表 → ③中文解读 1~3 句（先“系数符号+显著性”，再“经济含义”）。
13. **样本量**：每步报 N（面板另报截面数 N_g 与年份数 T）；某步样本量骤减必须说明原因（如剔除直辖市、缩短时间窗）。
14. **多重检验校正**：涉及多个被解释变量、多组异质性或多个机制变量时，**按“检验族”分组**校正（Bonferroni/Holm/FDR q；
    Python 用 statsmodels.multipletests），并说明校正前后差异。
15. **识别假设披露**：每步用 1~2 句说明关键识别假设——条件独立/无遗漏混淆（D ⊥ U | X）、**重叠/共同支撑
    （0 < P(D=1|X) < 1，必报倾向得分取值范围与重叠诊断，必要时修剪样本）**、PLIV 的**相关性 + 排他性（含弱 IV 检验）**、
    二元工具下的 **LATE 解释**、面板 DiD 框架下的**平行趋势**；不把相关性结果当因果结论。
16. **稳健性与安慰剂**：稳健性必须同时覆盖**数据层**（调整样本、缩尾、FE 调整、剔除并行政策）与**模型层**
    （改 K 折/分割比例、换学习器、换模型形式 IRM/LPQ、PLIV），至少 3~5 项；政策/试点类研究补充**安慰剂检验**（政策时点前移、随机化置换），
    并可加**遗漏变量敏感性分析**（DoubleMLDID 的 sensitivity_analysis 或等价思路）。
17. **诚实披露**：未通过/异常明确说明并给补救建议；披露“做了但未报告”的全部回归，防选择性报告；
    用 Python 替身时在交付物与讨论里明确标注，不冒充 Stata。

## 全程通用约定
- 处置变量记为 **D**，被解释变量记为 **Y**，控制变量集记为 **X**，工具变量记为 **Z**，机制变量记为 **M**。
- 核心估计量：部分线性模型 PLR 的处置系数 **θ̂**；Neyman 正交得分 ψ̂ = (D − m̂(X))·(Y − ĝ(X) − θ̂(D − m̂(X)))。
- 标准误：SE(θ̂) = sqrt( Var(ψ̂) / n )；聚类稳健时按聚类层级对 ψ̂ 聚合。
- 默认设置：**K=5 折交叉拟合、随机种子固定、随机森林基准学习器、控制变量一次项+二次项、个体与时间固定效应**。
  所有默认均可被用户/研究设计覆盖，但必须在脚本与表注中写明。

## 步骤 0：数据导入、清洗、面板设定

**做什么**：把原始数据读成可用面板，核对变量，建立可复现口径。

**方法模型**：无（数据工程）。
- Stata：`import delimited/import excel/use`；`destring`、`encode`；`xtset city year`；`xtdescribe` 看是否平衡。
- Python：`pd.read_csv/read_excel/read_stata`；`astype`/`pd.Categorical`；设 MultiIndex `(id, year)`。

**要输出**：①样本筛选流程图（模板：原始样本 N0 → 剔除关键变量缺失 → N1 → 剔除异常/缩尾 → N2 → 设定面板/滞后 → 最终样本 N3，每步报 N 与剔除原因）；②变量定义表（名称、含义、单位、来源、类型、是否取对数）。

**怎么读**：样本量、缺失率、面板是否平衡决定后续稳健性设计（如某变量 2014 年才开始统计 → 需补样本区间回归）。

## 步骤 0.25：被解释变量/复合指标测算（可选）

**做什么**：当 Y 是合成的指数/评分时（如包容性绿色增长、高质量发展、绿色全要素生产率），先把测算口径定死并写清。

**方法模型**（选一，并在稳健性中更换口径交叉验证）：
- 指标体系 + 赋权：主观 AHP / 德尔菲，客观熵权 / 变异系数，主客观组合赋权，熵权 TOPSIS。
- 数据包络（DEA/SBM/超效率 SBM，含非期望产出）测算效率指数。
- 主成分（PCA）/ 因子分析合成。
- 指标先正向化、标准化（极差/均值方差），维度加权，映射到可读区间（如 0~10）。

**要输出**：①指标体系表（维度 → 具体指标 → 单位/方向 → 权重）；②测算方法与公式；③指数描述性概览；④**换权重/换维度指标的敏感性对照表**（熵权 vs 组合赋权 vs PCA，各口径下 θ̂ 是否一致）。

**怎么读**：指数口径直接影响结论，必须披露且做“更换测算口径”的稳健性；不同口径结论分歧大时如实说明。

## 步骤 0.5：研究设计摘要（硬性门控）

**做什么**：在跑任何回归前，先交一页以内“研究设计摘要”，停下等用户确认。

**要输出**（必须包含）：
1. 识别策略：D 来自何处（政策试点/自然实验/观测），主要威胁排序（遗漏变量、反向因果、选择、测量）。
2. DML 模型形式选择与理由：PLR（线性同质处置效应）还是 IRM（异质）或 PLIV（内生）或 LPQ（Y 二元）。
3. D×Y 类型与处理层级：二元/连续/多值 × 连续/二元；变异发生在城市/企业/行业/个体哪一层。
4. X 与 FE 处理方式：一次项/二次项/交互；FE 用虚拟变量吸收 or 组内去均值；是否滞后一期。
5. 学习器选择：g(X)、m(X) 各用什么（lasso/随机森林/梯度提升/神经网络）；二元 D 用分类器。
6. K 折、聚类层级、随机种子。
7. 机制路径与异质性分组（如适用）。
8. **需用户确认的歧义点**（变量口径、样本范围、政策时点、聚类层级、是否滞后、复合指标测算口径等）。

**怎么读**：门控未通过（用户未确认）不得进入步骤 2。

## 步骤 1：描述性统计

**做什么**：对 Y、D、X、M 做描述统计与相关性概览。

**方法模型**：均值/标准差/最小/最大/中位数；处理组 vs 控制组差异（均值差 t 检验）；相关系数矩阵。
- Stata：`summarize, detail`、`ttest`、`pwcorr`。
- Python：`df.describe()`、`scipy.stats.ttest_ind`、`df.corr()`。

**要输出**：①三线表（全样本 + 分组）；②相关系数矩阵；③中文解读 1~3 句（样本特征 + 组间差异 + 潜在混杂提示）。

**怎么读**：组间均值差异是“描述性相关”，不代表因果；注意 D=0/1 两组在 X 上的不平衡 → 后续靠 DML 的高维控制处理。

## 步骤 2：基准回归（DML 主回归）

**做什么**：估计 D 对 Y 的平均处置效应 θ̂。

**方法模型**：先按 **D×Y 类型** 选模型，再按面板/时滞设计落地。

| 情形 | 主回归 g(X) | 辅助回归 m(X) | 模型 | 备注 |
|---|---|---|---|---|
| D 二元 + Y 连续 | 回归器(RF/lasso) | 分类器(RF/logit) | PLR | 最常用（本文） |
| D 二元 + Y 二元 | 回归器 | 分类器 | LPQ(logit)/LPM | 报边际效应 |
| D 连续 + Y 连续 | 回归器 | 回归器 | PLR | 连续强度处置 |
| D 多值 + Y 连续 | 回归器 | 多分类器 | PLR/IRM | 多组处置 |

部分线性模型：Y = θ·D + g(X) + U；辅助回归 D = m(X) + V；交叉拟合估计 ĝ、m̂，再用残差正交化求 θ̂。
面板：X 中加入个体与时间虚拟变量（或用组内去均值）；Y 可滞后一期（Y_{t+1}，避免反向因果、体现政策滞后）。

**Stata（ddml + pystacked，示意模板，以 `help ddml`/`help pystacked` 为准）**：
```stata
* 安装（首次）
ssc install ddml, replace
ssc install pystacked, replace      // 需本机 Python + scikit-learn；无 Python 用原生 lassocv 退回
* 定义
global Y igg
global D broadband
global X edu sci urban inv inter consump constru fis unemp size cap pass fre
set seed 20231023
* 初始化部分线性模型：5 折交叉拟合、重复 5 次
ddml init partial, kfolds(5) reps(5)
* 主回归 E[Y|X]（连续结局 → type(reg)）
ddml E[Y|X]: pystacked $Y $X, type(reg) methods(ols lassocv rf gradboost)
* 辅助回归 E[D|X]（二元处置 → type(class)；连续处置 → type(reg)）
ddml E[D|X]: pystacked $D $X, type(class) methods(logit lassocv rf gradboost)
* 交叉拟合 + 估计
ddml crossfit
ddml estimate, robust cluster(city)
```

**Python（DoubleML，标注「Python 替身」）——Y 连续**：
```python
import numpy as np, pandas as pd
import doubleml as dml
from sklearn.ensemble import RandomForestRegressor, RandomForestClassifier

df = pd.read_csv("data.csv")
y = df["igg"].values
d = df["broadband"].values
X = df[["edu","sci","urban","inv","inter","consump","constru","fis","unemp","size","cap","pass","fre"]].values

ml_g = RandomForestRegressor(n_estimators=100, max_features=10, max_depth=5, min_samples_leaf=2, random_state=2023)
ml_m = RandomForestClassifier(n_estimators=100, max_features=10, max_depth=5, min_samples_leaf=2, random_state=2023)  # 二元 D

data = dml.DoubleMLData.from_arrays(X, y, d)
plr = dml.DoubleMLPLR(data, ml_g=ml_g, ml_m=ml_m, n_folds=5, score="partialling out")
plr.fit()
print(plr.summary)          # coef / std err / 95% CI
print("theta =", plr.coef, "se =", plr.se)
```

**Python——Y 二元（logit 部分线性 LPQ，或退化为 LPM）**：
```python
# 二元结局：逻辑部分线性，估计条件对数优势比（再换算边际效应）
lplr = dml.DoubleMLLPQ(data, ml_g=ml_g, ml_m=ml_m, n_folds=5)
lplr.fit()
# 或简单线性概率：仍用 DoubleMLPLR（Y 为 0/1 即可）
```

**要输出**：①代码；②三线表（全样本 + 一次项 → 加二次项 → 缩窄样本区间）；③**重叠性/共同支撑诊断（硬性门控）**：
报倾向得分 P(D=1|X) 的分布（min/p5/p95/max + 直方图），极端值修剪（默认 0.05~0.95），并报修剪前后 N 与 θ̂ 对照（见 `references/diagnostics.md` D2）；④中文解读（符号+显著性+经济含义）。
二元 Y 用 LPQ 时另报边际效应 APE（见 `references/diagnostics.md` D3）。

**怎么读**：θ̂ 显著为正/负 → 假设 H1 是否成立；表注写明学习器、K 折、FE、是否滞后一期、聚类层级；DML 通常不直接给 R²，报 θ̂/SE/95% CI。

## 步骤 3：分维度/分指标回归（多个 Y，可选）

**做什么**：当 Y 是综合指数时，分别对每个子维度/子指标重复步骤 2。

**方法模型**：同 PLR，逐个替换 Y。
- 例（张涛2023）：总指数 IGG 拆为 EG（经济增长）、ID（收入分配）、WB（福利普惠）、PR（环保减污）。

**要输出**：①多列三线表（每列一个 Y）；②系数对比图；③解读（哪个维度驱动总效应、哪些不显著及原因）。

**怎么读**：多 Y 属于同一“检验族”，按全局规则 14 做多重检验校正；不显著的维度如实讨论。

## 步骤 4：稳健性检验（选 3~5 项，须同时覆盖数据层与模型层）

> 目标：证明 θ̂ 的显著性与方向不依赖具体设定。数据层与模型层都要做。

### 4.1 调整研究样本（数据层）
- 剔除处理组/控制组中基础差异过大的子样本（如剔除 7 个宽带薄弱省 + 4 个直辖市）；缩窄时间窗到政策发布前后对称区间（如 2012–2018）。

### 4.2 剔除异常值（数据层）
- 对除 D 外的所有变量做 1%/99% 与 5%/95% 缩尾后重跑。**D 不缩尾。**

### 4.3 更换/增加固定效应（数据层）
- 基准只加城市+时间 FE，稳健性加「省份×时间」交互 FE，控制同省城市间随时间变动的共同冲击。

### 4.4 剔除并行政策（数据层）
- 找出与 D 同期推行的其他政策（如“智慧城市”“国家大数据综合试验区”），构建其政策虚拟变量并入 X 后重跑。

### 4.5 重设 DML 模型（模型层，最关键）
1. **改交叉拟合折数/分割比例**：K=5 → K=2、K=10（对应分割比例 1:1、1:9）。
2. **更换学习器**：随机森林 → 套索回归（lasso CV）、梯度提升（gradboost）、神经网络（nnet）。
3. **更换模型形式**：PLR → 交互式模型 IRM：Y = g(D, X) + U，θ̂ = E[ ĝ(1,X) − ĝ(0,X) ]。
   - Stata：`ddml init interactive`；主回归 `ddml E[Y|D X]: ...`，辅助 `ddml E[D|X]: ...`。
   - Python：`dml.DoubleMLIRM(data, ml_g=ml_g, ml_m=ml_m, n_folds=5)`（ml_g 为连续回归器）。
   - Y 二元时：PLR/LPM → `dml.DoubleMLLPQ` 交叉验证。

### 4.6 安慰剂/虚假政策时点检验（模型层，政策类推荐）
- 把政策发生时间整体前移 2~3 期（虚假时点）重跑，θ̂ 应不再显著。
- 或随机打乱 D 的归属（随机化置换，重复数百次），看真实 θ̂ 是否落在置换分布尾部（如 >95% 分位）。

### 4.7 更换被解释变量测算口径（数据层，Y 为指数时）
- 更换赋权方法（熵权 vs 组合赋权 vs PCA）、或更换维度指标后重跑，验证结论不依赖具体测算口径。

### 4.8 遗漏变量敏感性分析（模型层，必做，审稿标配）
- 量化未观测混淆：partial R² 框架（Chernozhukov–Cinelli–Newey–Sharma–Syrgkanis 2024），报告使 θ̂ 归零所需的混淆强度（临界 cf_y/cf_d/rho）。
- Python：`dml_obj.sensitivity_analysis(cf_y=0.03, cf_d=0.03, rho=1.0)`（PLR/IRM/PLIV/LPQ 均支持）；Stata ddml 无内置时显式说明并附 Python 结果。
- 详见 `references/diagnostics.md` D1。

**要输出**：每种稳健性一行/一列的系数汇总表；解读“显著性不变、方向不变、数值变化在合理范围 → 结论稳健”。

**怎么读**：若某项稳健性使 θ̂ 变号或失显著，必须如实报告并分析原因，不得藏匿。

## 步骤 5：内生性处理（部分线性工具变量 PLIV）

**做什么**：处理 D 的内生性（遗漏变量、测量误差、反向因果），用工具变量识别。

**方法模型**：PLIV
Y = θ·D + g(X) + U；Z = m(X) + V（Z 为工具变量）；用 Ẑ 残差正交化求 θ̂。
- 工具变量要求：**相关性**（Z 与 D 显著相关，第一阶段 F 统计量 > 10，报弱 IV 检验）、**排他性**（Z 只通过 D 影响 Y）。
- 二元工具 + 异质处置下，解释为 **LATE**（对“顺从者”的局部平均处置效应），并说明外推边界。
- 例（张涛2023）：Z = 城市地形起伏度 × 时间趋势（Nathan & Nancy, 2014 思路）。

**Stata**：
```stata
ddml init iv, kfolds(5) reps(5)
ddml E[Y|X]: pystacked $Y $X, type(reg) methods(ols lassocv rf gradboost)
ddml E[D|X]: pystacked $D $X, type(reg) methods(ols lassocv rf gradboost)
ddml E[Z|X]: pystacked $Z $X, type(reg) methods(ols lassocv rf gradboost)
ddml crossfit
ddml estimate, robust cluster(city)
```
**Python**：`dml.DoubleMLPLIV(data, ml_g=ml_g, ml_m=ml_m, ml_r=ml_r, n_folds=5)`（ml_r 为 Z 对 X 的回归器）。

**要输出**：①PLIV 系数表；②第一阶段相关性诊断（Z→D 的系数/显著性/F 统计量/弱 IV 检验）；③解读（IV 估计与基准比较：放大/缩小？是否一致；LATE 口径说明）；④遗漏变量敏感性分析（`dml_pliv.sensitivity_analysis()`，见 `references/diagnostics.md` D1）。

**怎么读**：报告相关性+排他性论证；弱工具变量时如实说明并讨论偏误方向；必要时加**遗漏变量敏感性分析**（Python `DoubleMLDID` 的 `.sensitivity_analysis()` 或等价思路，量化“多大程度的遗漏混淆能推翻结论”）。

---

## 步骤 6：异质性分析（分组回归 / 交互项 / CATE 三法）

**做什么**：检验 D 的效应在不同子群体/地区间的差异。

**方法模型**（按稳健性递增排序）：
1. **分组回归**：按分组变量切样本，每组各跑一次 PLR，比较 θ̂（最直观，但组间 X 分布不同，不可直接比大小）。
2. **交互项**：在 PLR 中构造 D×分组虚拟变量的交互项，直接估计组间处置效应差（对“差异的显著性”更可靠）。
3. **CATE/因果森林**：用 IRM 或因果森林（如 `econml` 的 CausalForestDML）估计条件平均处置效应 τ(X)，刻画异质性的函数形态（进阶）。
- 常见分组维度：资源禀赋、工业基础、城市等级、区位、产权、规模、政策强度等。
4. **BLP/GATES（异质性推断标配）**：BLP 检验 CATE 预测是否含信息、是否存在异质性；GATES 按预测 CATE 排序分 5~10 组估组 ATE，给同时覆盖所有组的 honest 置信区间（Chernozhukov–Demirer–Duflo–Fernández-Val 2024）。Python：拟合 IRM 后 `irm.cate(basis=...)`（BLP）、`irm.gate(groups=哑变量)`（GATES），底层 `DoubleMLBLP`；详见 `references/diagnostics.md` D4。

**要输出**：①分组系数三线表（每组一列，报各自 N）；②BLP 与 GATES 结果（β1/β2、各排序组 ATE 与 honest CI）；③分组条形图/森林图；④解读（差异显著性用交互项或 GATES，多重检验校正）。

**怎么读**：重点看“显著 vs 不显著”和方向，组间差异显著性用交互项法；多组属于同一检验族 → 多重检验校正。

## 步骤 7：机制检验（DML 因果中介）

**做什么**：检验 D 通过机制变量 M 影响 Y 的传导路径。

**方法模型**（Farbmacher et al., 2022 思路，两种分解）：
1. 总效应 θ̂_total：PLR 对 Y ~ D（控制 X）。
2. 第一阶段：PLR 对 M ~ D（控制 X），得 D 对 M 的效应。
3. 直接效应 θ̂_direct：PLR 对 Y ~ D，把 M 加入 X 一起控制。
4. 间接效应：**系数差法** = 总效应 − 直接效应；或**系数乘积法** = (D→M 系数)×(M→Y 系数)。
5. 间接效应的标准误：bootstrap（分位数置信区间）或 Delta 法；**多重中介**同时放入多个 M 或逐条检验并说明相关性。
- 分组报告：处置组 / 控制组各自的直接效应与间接效应（如张涛2023 表2）。
- **中介变量内生性**：M 可能同样内生，须披露并讨论（结果解释为“条件于 M 的分解”，非严格因果中介）。

**要输出**：①机制分解表（总效应 / 处置组直接 / 控制组直接 / 处置组间接 / 控制组间接）；②机制路径图；③解读（每条机制是否成立、间接效应相对大小）。

**怎么读**：间接效应显著 → 该机制成立；直接效应仍显著 → 存在其他机制或直接渠道；机制变量内生性/反向因果要披露。

## 步骤 8：进一步讨论/扩展（可选）

**做什么**：在基准之外回答更有政策含义的延伸问题。

**方法模型**：灵活（仍是 DML 或派生指标回归）。
- 例（张涛2023）：把 Y 换成“相对经济差距”指标（本城市值 / 区域最大值），检验 D 对全国、南北、胡焕庸线两侧、沿海内陆、省内中心-外围相对差距的影响。
- 分批次政策（staggered）：**正式步骤**——用 `DoubleMLDID`/`DoubleMLDIDCS`（含自带敏感性分析），报告处置前后各期效应与平行趋势（见 `references/diagnostics.md` D9）。
- 连续处置剂量-反应：`econml.CausalForestDML(discrete_treatment=False)` 估计 ADRF 与置信带（见 `references/diagnostics.md` D6）。
- 空间/溢出：构造邻接加权变量或空间杜宾型设定（谨慎，需额外识别假设）。

**要输出**：①扩展回归表；②解读（结论对政策/区域的启示）。

**怎么读**：明确这是“进一步讨论”而非核心识别结果，语气与结论边界保持一致。

## 附录 B：常见问题与诊断
1. **重叠性/共同支撑**：报告 P(D=1|X) 的取值范围；若大量集中 0 或 1 → 重叠性弱，需修剪样本或换模型，并在文中说明。
2. **弱工具变量**：第一阶段 F 统计量 < 10 提示弱 IV；报告并讨论偏误方向。
3. **学习器不收敛/过拟合**：用交叉拟合 + 折内调参；报告折外性能（R²/MSE/AUC）；必要时换更稳健的集成学习器。
4. **聚类层级错误**：D 在城市层变异却聚到个体层 → 标准误偏小、假显著；必须聚到城市层。
5. **信息泄漏**：在交叉拟合折外预测、折内调参，严禁用全样本训练后再预测。
6. **尺度敏感**：lasso/神经网络对尺度敏感，先标准化；树模型（RF/GBM）不需要。
7. **遗漏变量混淆**：报告 partial R² 敏感性边界（D1）；临界混淆越小结论越脆。
8. **异质性推断**：用 BLP/GATES + 多重检验，勿仅凭分组各自显著下结论（D4）。
9. **聚类数少**：wild cluster bootstrap（`wildboottest`/`boottest`）替代普通聚类 SE（D5）。
10. **折内标准化/插补**：标准化、缺失插补、编码须折内进行，避免泄漏。
11. **二元结局边际效应**：LPQ 报 APE + Delta/bootstrap SE，或补 LPM 对照（D3）。

## 附录 E：开跑前一键自检（Checklist）
- 数据：面板设定、缺失值、缩尾、变量类型、复合指标口径。
- 识别：D 类型与处理层级、重叠性、平行趋势（DiD 框架）/排他性（IV）。
- 模型：PLR/IRM/LPQ/PLIV 选择、FE 处理、滞后一期、K 折、学习器、种子。
- 推断：聚类层级 ≥ 处理层级、95% CI、多重检验校正。
- 稳健性：数据层 ≥ 2 项 + 模型层 ≥ 2 项 +（政策类）安慰剂。
- 交付：do/py 脚本、结果汇总表、假设判定矩阵、图表清单、讨论、未通过说明。
- 敏感性：遗漏变量 partial R² 边界（D1）。
- 异质性：BLP/GATES + 多重检验（D4）。
- 聚类：wild bootstrap / 双向聚类（D5）。
- 重叠性：倾向得分分布 + 修剪（D2）。
