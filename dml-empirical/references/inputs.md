# 输入清单、自动推断与默认值

开始分析前按此清单收集信息。只给「最小必需输入」即可启动，其余自动推断或取默认，
并在最终交付物的「假设与默认清单」中标注。

## 最小必需输入（缺了会停下询问）
1. 数据文件路径（.dta/.csv/.xlsx；变量名大小写敏感，须与文件完全一致）。
2. 被解释变量 Y 的名称。
3. 处置变量 D 的名称，及其变异/政策性质（一次性试点及年份 / 连续渐进 / 分批次 staggered / 自然实验）。
4. 样本结构（截面单位 × 时间范围；面板还是截面）。

## 强烈建议（给不了就用默认，并在交付物标注）
- 研究问题与预期假设 H1/H2…
- 控制变量 X 清单
- 固定效应层级
- 聚类层级
- 政策/事件时点（DiD/政策类需要）
- 机制变量 M 与机制类型（直接 D→M / 中介 D→M→Y / 调节 D×M→Y）
- 分组/异质性变量（须为处理前或时间不变特征）

## 自动推断与默认（只给最小输入也能自动完成）
| 事项 | 自动推断 / 默认规则 |
|---|---|
| 数据读入 | 按扩展名：.dta→use/read_stata；.csv→import delimited/read_csv；.xlsx→import excel/read_excel |
| 面板结构 | 存在「个体标识 + 年份」两列→面板；自动 xtset / 设 MultiIndex；报告是否平衡 |
| D 类型 | 取值 ⊆ {0,1}→二元（m̂ 用分类器）；连续数值→连续强度（m̂ 用回归器）；>2 个离散值→多值（多分类器） |
| Y 类型 | 0-1→二元（LPQ/logit 或 LPM）；连续→PLR/IRM |
| X 默认 | 数据中除 Y、D、标识、时间、机制变量外的其余变量；高维时自动加二次项 |
| 固定效应 | 默认个体 FE + 时间 FE（虚拟变量纳入 X，或组内去均值） |
| 聚类层级 | 默认 = D 的变异/处理发生层级（城市政策聚城市、行业政策聚行业） |
| 学习器 | 默认随机森林（主/辅助回归各一）；稳健性换 lasso、梯度提升、神经网络 |
| 交叉拟合 | 默认 K=5 折、reps=5 |
| 随机种子 | 默认固定（如 20231023），并保存 folds 变量 |
| 缩尾 | 连续 Y/X 双侧 1%；D 不缩尾 |
| 滞后一期 | 政策存在时滞或反向因果风险时默认 Y_{t+1}，并说明 |
| 输出目录 | 默认 ./outputs |
