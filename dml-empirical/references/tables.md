# 三线表（booktabs）期刊级格式规范（硬性）

> 适用范围：本 skill 产出的**所有结果表**——描述统计、基准回归、稳健性、内生性（PLIV）、
> 异质性、机制分解、扩展——必须严格按本规范输出为论文期刊三线表。
> **可复制性为硬性红线**：结果表必须是可选中、可复制、可编辑的**文本表格**，
> 禁止以 PNG/PDF 图片作为结果表（图片无法复制、无法编辑，属不规范交付）。

## 0. 交付形式（可复制，最高优先）
- 结果表按以下**文本**形式交付（任选其一或多种，优先级从上到下）：
  1. **Markdown 三线表**（聊天内可直接复制）：三线结构用 Markdown 表格语法 + 表注。
  2. **Word 原生三线表**（python-docx 设置边框：仅顶线粗、栏目线细、底线粗，无竖线、无内横线），单元格文本可选中复制。
  3. **LaTeX booktabs**（`\toprule` `\midrule` `\bottomrule`）或 **CSV**（DataFrame 导出）。
- **图片仅用于真正的“图”**：coefplot、事件研究图、重叠性诊断图、机制分解图、异质性森林图、安慰剂图；
  结果表一律用文本，不渲染成图片。
- Stata：优先 `stata_etable`（原生可复制表格）；备选 `esttab`/`estout` 的 `booktabs` 选项。
- Python 替身：DataFrame 导出 CSV；再生成 Markdown 三线表（聊天内）与 Word 原生三线表（报告）。

## 1. 三线结构（硬性红线）
- 表中只有三条横线，多一条或任何竖线即判不合格：
  - **顶线**（表格顶部）：粗线，约 1.5pt；
  - **栏目线**（表头与数据之间）：细线，约 0.75pt；
  - **底线**（表格底部）：粗线，约 1.5pt。
- 禁止竖线；禁止数据行之间的横线。
- 仅当表头需要分组（如「处理组 / 控制组」两个栏目族）时，允许在分组栏目上方加一条 0.5pt 辅助细线，其余一律不加。

## 2. 表题与编号
- 表题置于表格**正上方、居中**。
- 编号连续，格式 `表1 …` / `Table 1 …`，全文统一。
- 表题必须**自明**：读者不看正文即可理解（对象、口径、样本区间、被解释变量）。
- 表题不加句号结尾，不堆砌口号。

## 3. 表头（栏目行）
- 每个栏目必须有项目名称；计量单位写在名称后括号内，如 `ln_gdp（对数）`、`Y（指数）`。
- 符号规范：变量符号（Y、D、X、M、Z）与估计量（θ̂、β̂）用**斜体**；`SE`、`N`、`95% CI` 用正体。
- 表头不重复表题已含信息。

## 4. 数据对齐与小数位
- 数值列**右对齐、小数点对齐**；变量名/模型名列左对齐；表头居中。
- 同一列小数位统一：系数 3~4 位；标准误（或 t/z 值）3~4 位（置括号内）；p 值 3 位（<0.001 记 0.000 或以星号替代）；
  95% CI 3 位；N 取整数。
- 缺失/不适用用 `—`，不留空。

## 5. 回归表专项
- 每列一个模型，模型列用 `(1)(2)(3)…` 编号，表头写明被解释变量。
- 系数加显著性星号：`*** p<0.01`、`** p<0.05`、`* p<0.1`（星号上标于系数）。
- 标准误（或 t/z 值）置于系数**下方括号内**，两行一组。
- 需要时另起一行给 95% CI。
- 表底部用勾选行标注设定：控制变量（一次项/二次项）、城市 FE、年份 FE、聚类层级、学习器。
- DML 表不报 R²（机器学习模型无经典 R²），改报 θ̂、标准误、95% CI、N，并在表注说明。

## 6. 表注（表格下方，以「注：」开头，字号小于正文）
至少包含：
① 显著性水平说明；② 标准误类型与聚类层级；③ 控制变量与固定效应；④ 学习器与交叉拟合折数（K、reps）；
⑤ 数据来源、缩尾（1%/99%）与滞后一期；⑥ 多重检验校正（Bonferroni/Holm/FDR，如有）；⑦ 引擎标注（Stata ddml 或 Python 替身）。

## 7. 字号与排版
- 表格整体居中，宽度不超过版心。
- 表内字号一般比正文小一号（五号/小五），表题黑体。
- 数字用 Times New Roman 类衬线字体，中文用宋体/黑体。

## 8. 常见错误自查（交付前逐项核对）
- [ ] 结果表为**可复制文本**，未用 PNG 图片充当结果表
- [ ] 无竖线、无多余横线（只保留顶线/栏目线/底线）
- [ ] 表题编号且自明
- [ ] 表头有单位、变量符号斜体、统计量正体
- [ ] 数值右对齐、小数位统一
- [ ] 系数上方星号 + 下方括号标准误（或 t/z），位置规范
- [ ] 表注含聚类层级/学习器/折数/引擎/缩尾
- [ ] 每列报 N
- [ ] 多组检验已说明多重检验校正

## 9. 模板示例（文本三线表，可直接复制）

```
表2 基准回归与稳健性（被解释变量：Y 城市创新指数）

模型                (1)OLS-FE   (2)DML-PLR   (3)DML-PLR(b)  (4)Lasso    (5)PLIV
D                   0.249***     0.331***     0.259***      0.367***   0.230***
                   (0.027)      (0.024)      (0.054)       (0.022)    (0.052)
95% CI             [0.197,0.302] [0.284,0.377] [0.152,0.365] [0.323,0.410] [0.127,0.332]
控制变量             YES          YES          YES           YES         YES
城市FE              YES          YES          YES           YES         YES
年份FE              YES          YES          YES           YES         YES
聚类层级             城市          城市          城市          城市         城市
N                   2000         2000         2000         2000        2000

注：括号内为聚类稳健标准误；*** p<0.01，** p<0.05，* p<0.1。DML 各行学习器为随机森林
（K=5 折、5 次重复交叉拟合），Lasso 行使用 LassoCV；PLIV 工具变量为地形起伏度×时间趋势，
一阶段偏 F≈469。引擎为 Python 替身（DoubleML 0.11.4）。
```

## 10. 导出与交付要求（可复制性为硬性红线）
- **结果表必须为可复制的文本表格**，禁止以 PNG/PDF 图片作为结果表——图片无法选中/复制/编辑，属不规范交付。
- Markdown 三线表按第 9 节模板输出（聊天内可直接复制）；Word 报告用**原生三线表**（设置边框：顶线粗、栏目线细、底线粗、无竖线），不用图片。
- LaTeX 用 booktabs（`\toprule`/`\midrule`/`\bottomrule`）；CSV 用 DataFrame 导出作为机读附件。
- 图（coefplot、事件研究图、重叠诊断、机制分解图、异质性森林图、安慰剂图）可用 PNG 图片，但**结果表一律用文本**。
- Stata：优先 `stata_etable`（原生可复制表格）；备选 `esttab`/`estout` 的 booktabs 选项。
