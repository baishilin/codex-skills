# 分析步骤模板（第 0~8 步）

> **引擎说明**：以下命令按 Stata 书写。若实际使用 Python 替身引擎（Stata MCP 未连接），
> 把命令等价翻译为 Python：`reghdfe` → `linearmodels.PanelOLS`、`logit/probit` → `statsmodels`、
> `winsor2` → `scipy.stats.mstats.winsorize`、`ttest` → `scipy.stats.ttest_ind`、
> `coefplot` → matplotlib/PIL 系数图，并在所有输出与讨论中标注「Python 替身」。


> 每步按“做什么 / 方法模型 / 要输出 / 怎么读”展开。不适用步骤整段删除。
> 全局规则见 SKILL.md；输入清单见 inputs.md。

## 第 0 步：数据导入、清洗与面板设定（数据已清晰可跳过）
- **做什么**：读入数据 → 核对变量与类型 → 处理缺失/异常 → 缩尾（如需）→ 生成分析变量 → 贴标签 → xtset → 保存工作数据。
- **方法/模型**：无建模。
- **要输出**：①样本结构（观测数、截面数、各年观测数、平衡/非平衡）；②关键变量缺失值计数与处理说明；③缩尾前后 D 描述对比（若缩尾）；④面板设定结果；⑤样本筛选流程图；⑥变量定义表（变量名、含义、单位、构造、来源）。
- **怎么读**：确认 Y/D/X 无关键缺失、类型正确、量纲合理，面板设定成功且样本量符合预期。

## 第 0.5 步：研究设计确认（关键，跑回归前必做）
- **做什么**：先不跑回归。基于“文献综述 + 数据字典 + 研究假设”输出一页以内“研究设计摘要”，供用户确认。
- **要输出**：①识别策略（D 的变异来源、为何可/不可视为外生，主要威胁排序）；②基准模型选择与理由；③变量与假设清单（Y、D、X、M、分组变量，H1/H2…）；④机制类型与检验路径；⑤预期符号；⑥需用户确认的歧义点。
- **门控**：输出后停下等待确认/修改，确认后再进入回归。

## 第 1 步：描述性统计
- **做什么**：主要变量描述统计、相关性与图形证据。
- **方法/模型**：`summarize {Y} {D} {X}, detail`；`pwcorr {Y} {D} {X}, sig`；按 D 分组的均值差异检验（`ttest {Y}, by({D组})` 或分组 tabstat）。图形至少 1~2 张：Y 与 D 的时间趋势、按 D 分组的均值对比、主要连续变量直方图/密度、相关性热图。
- **要输出**：①Y/D/X 的 N/均值/标准差/最值/中位数；②按 D 分组的 Y 均值与 t 检验 p 值；③相关矩阵；④图形。
- **怎么读**：样本量与量纲正常；D 分布符合预期；核心变量间无异常强相关（|r|>0.8 提示共线性）。

## 第 2 步：基准回归

### 2.A 分支 A：D 为连续变量/一般处理（默认）
- **方法/模型**（按 Y 类型选）：
  - Y 连续 → 双向固定效应 OLS：`reghdfe {Y} {D} {X}, absorb({FE}) vce(cluster {聚类})`
  - Y 为 0-1 → logit/probit（用 `margins, dydx(*)` 报边际效应与聚类标准误）
  - Y 为计数 → Poisson/负二项（报发生率比或边际效应）
  - Y 为截断 → Tobit（报边际效应）
- **基准表多列递进**：(1) 仅 D；(2) +控制变量；(3) +个体固定效应；(4) +年份固定效应；(5) 双向固定效应（主设定）；(6) 可选行业×年份等高维固定效应对照。每列报系数、SE、显著性、N、R²，表注注明聚类层级。
- **估计方程**：写清方程（如 Y_it = β0 + β1·D_it + γ·X_it + μ_i + λ_t + ε_it）。关键参数 β1。
- **要输出**：D 系数、SE、t/z、显著性、95% CI、N、R²（组内）、模型整体 F、多重共线性检验（vif，VIF>10 提示）、经济显著性（一个标准差带来的 Y 变化）。
- **怎么读**：β1 符号与显著性符合假设；系数在多列间稳定（符号不变、量级合理）。
- **注意**：加个体固定效应前先诊断 D 的 within/between 变异占比；若 D 在个体内几乎无变异，会被个体 FE 吸收，需回到 0.5 步重选识别策略。

### 2.B 分支 B：D 为政策/制度/自然实验冲击（DiD / 事件研究）
- **适用**：D 为一次性政策试点、法规出台或准自然实验。不要直接套双向固定效应 OLS（交错/异质性处理下会负权重偏误）。
- **方法/模型**（选一并说明理由）：交错 DiD 用异质性稳健估计量 `csdid` / `eventstudyinteract` / `did_imputation` / `did_multiplegt`；处理时点一致时可用经典 DiD：`reghdfe {Y} i.treat##i.post {X}, absorb({个体FE} {时间FE})`。
- **必做**：①事件研究图（政策前各期系数应不显著、接近 0；**明确基准期，默认 t-1**）；②Goodman-Bacon 分解（bacondecomp）或负权重诊断；③安慰剂检验（随机化处理组/处理时点，见第 4 步）。
- **要输出**：DiD 系数（或各期系数）、事件研究图、平行趋势检验结论、样本量（处理组/对照组数量与各期分布）。
- **怎么读**：政策前系数不显著且平坦 → 平行趋势成立；政策后显著且方向符合假设 → 因果效应成立；存在前趋势则回到 0.5 步重新考虑识别。

## 第 3 步：分维度/分指标回归（可选，没有就删）
- **做什么**：把 Y 拆成 Y1/Y2… 或把 D 拆成 D1/D2… 分别回归，识别效应来源。
- **方法/模型**：同基准（或基准选定的 DiD 估计量）。
- **要输出**：一张汇总表：每维度一列，报 D（或 Di）系数、SE、显著性、N；对这组系数做多重检验校正（rwolf / Bonferroni / FDR）。
- **怎么读**：哪些维度“校正后”仍显著 → 总效应主要来自哪一维度；勿因个别维度显著就下结论。

## 第 4 步：稳健性检验（每项各做一次，最后汇总一张对照表）
- **做什么**：检验基准结论稳健。从清单选 3~5 项：
  - 换样本/排除特殊样本（直辖市、金融危机年、疫情年等）
  - 缩尾强度（无缩尾、1%、2.5%、5%）并用 coefplot 画系数变化
  - 替换被解释变量代理指标 / 替换核心解释变量度量
  - 更换标准误（robust、双向聚类、更换聚类层级、聚类数少时 wild cluster bootstrap）
  - 增加或更换固定效应（行业×年份、地区×年份等）
  - 加入遗漏控制变量（行业 HHI、地区 GDP 增速等）
  - 更换模型（OLS→Tobit、logit↔probit、计数分布替换）
  - 安慰剂检验：随机化处理组（置换检验 500/1000 次得置换 p 值）或随机化处理时点
  - 排除同期其他政策/事件干扰
  - 平行趋势/前趋势检验（DiD 必做）
- **方法/模型**：每次只改一处，其余与基准一致；各单项分别跑，最后合并为一张表与基准并列。
- **要输出**：D 系数、SE、显著性、N，与基准对照；coefplot 汇总各稳健性系数点估计与置信区间。
- **怎么读**：方向与显著性基本不变 → 结论稳健；改变则解释原因。

## 第 5 步：内生性处理（选 1~2 种并说明理由）

### 5.1 工具变量 IV
- `ivreg2 {Y} {X} ({D}={Z}), first cluster({聚类})` 或 `ivreghdfe`。
- 报告：①第一阶段表（工具变量系数、第一阶段 F）；②弱工具变量检验：Kleibergen–Paap rk Wald F（或 Cragg–Donald F）与 Stock–Yogo 临界值；F>10 只是粗略经验值，现代文献要求与工具个数/期望偏误匹配的有效 F（Olea–Pflueger 2013），必要时做弱识别稳健推断（Anderson–Rubin，weakiv / rivtest）；③过度识别检验（Hansen J，**仅当工具数多于内生变量数时**；恰好识别无此检验）；④DWH/Hausman 内生性检验；⑤reduced form 表；⑥论证 Z 的相关性与排他性（制度背景）。

### 5.2 遗漏变量偏误检验（Oster / 系数稳定性）
- 用 `psacalc`（或手算 Oster 2019 δ）比较“无控制+无 FE”“无控制+有 FE”“仅控制+个体 FE”“全集”四组系数；约定 Rmax（通常 1.3×当前 R² 并说明），报告 δ；δ>1（越大越好）说明遗漏不可观测变量偏误可能较小；可用“逐步加控制看系数稳定”作简化替代。

### 5.3 PSM（倾向得分匹配）
- `psmatch2 {处理组D}, outcome({Y}) pscore(...)`；报告匹配方法（近邻/核/半径）、共同支撑检验、平衡性检验（pstest，匹配后标准化偏差 <10%）、ATT 及显著性；必要时用 Rosenbaum 边界（rbounds）做不可观测混杂敏感性。
- **面板注意**：psmatch2 是截面匹配工具，面板需先截面化（如取处理前一期匹配、或匹配后再跑 FE/DiD）；匹配变量必须在处理前测定。PSM 只解决可观测选择，不能替代 IV，解读时说明。

### 5.4 滞后解释变量（反向因果）
- 用 D 的滞后一期/多期作解释变量缓解反向因果；用“领先-滞后检验”（加入 D 的领先项，领先项显著则提示反向因果）作诊断。（DiD 场景与事件研究的前趋势检验复用。）

### 5.5 动态面板 GMM（模型含滞后因变量 Y_{t-1} 时）
- `xtabond2` 系统 GMM（Blundell–Bond）；报告 AR(1)/AR(2) 与 Hansen 检验（工具数不宜过多，防工具过度增殖），说明工具设置。

### 5.6 RDD（D 存在断点/门槛时）
- `rdrobust`；报告带宽选择（最优带宽）、局部多项式阶数、McCrary 密度检验（断点处是否操纵）、不同带宽稳健性；画断点图。

- **要输出**：第一阶段 F / 弱工具变量与过度识别检验 / Oster δ / 平衡性检验与 ATT / AR(1)AR(2) / 断点图，并与基准对比。
- **怎么读**：关键检验通过（有效 F 达标、δ>1、匹配后平衡、Hansen J 不拒绝、置换 p 显著）且结论不变 → 因果解释更可信。

## 第 6 步：异质性分析
- **做什么**：考察效应在不同群体间差异。分组变量必须是**事前（处理前）或时间不变**的个体特征（所有制、行业、地区、规模、市场化基线值），避免用事后结果变量或 D 的分位分组（否则选择偏误）。
- **方法/模型**：分组回归（reghdfe 按 {分组1/分组2/…} 分别跑）；或交互项 {D}×{分组变量}；组间差异用交互项显著性、suest 或自举组间差异检验（避免仅凭“一组显著一组不显著”断言差异）。
- **要输出**：一张汇总表：每行一组（或每交互项一列），报 D 系数、SE、显著性、N、各组样本量，给出组间差异检验与多重检验校正。可选分位数回归（qreg/xtqreg）。
- **怎么读**：只有组间差异检验显著才可下“异质性”结论；“显著性差异”不等于“差异显著”。

## 第 7 步：机制检验
先确定机制类型（选 1~2 种）：
- 直接检验（D→M）：D 是否影响中间变量 M（“渠道是否存在”）——识别假设最轻，**优先做**。
- 中介（D→M→Y）：D 是否通过 M 传导到 Y（“如何”起作用）——识别假设强，谨慎。
- 调节（D×M→Y）：M 是否改变 D 对 Y 的效应（“何时/对谁”起作用）。
- 判断口诀：M 回答“为什么/通过什么路径”→ 中介；M 回答“在什么条件下/对哪类主体更强”→ 调节。不要默认做中介。

### 7.1 机制变量直接检验（D→M，推荐）
- **做什么**：检验 D 是否显著影响各机制变量 M1 M2…。M 必须是“传导渠道/中间投入”，时间上先于或同期于 D，不能是事后结果变量（避免坏控制）。
- **方法/模型**：同基准，把 Y 换成机制变量；DiD 框架对机制变量同样做事件研究/DiD。
- **要输出**：一张表：每列一个机制变量，报 D 系数、SE、显著性、N，并做多重检验校正。
- **怎么读**：D 对某 M 显著且符号符合理论 → 可能是传导渠道（只是必要条件）。

### 7.2 中介效应分析（D→M→Y，谨慎使用）
- **警示**：经典逐步回归（Baron–Kenny）/Sobel 在顶刊中已被广泛批评——M→Y 阶段存在“中介-结局混杂”与坏控制问题，系数乘积法依赖正态假设。能直接检验就不要勉强做逐步中介；确需做时选因果中介并明示识别假设。
- **方法/模型**：{KHB 分解 / 因果中介（medeff、gsem）/ 基于 DiD 的中介分解}；处置=D、结局=Y、中介=M；bootstrap 报告间接效应的偏差校正 95% 置信区间（固定随机种子）。
- **要输出**：总效应、直接效应、间接效应及显著性/置信区间；明确写出“无中介-结局混杂”“无处置-中介交互”等识别假设及当前数据合理性。
- **怎么读**：总效应显著 + 间接效应显著（bootstrap 区间不含 0）→ 存在中介；直接效应仍显著为部分中介，否则完全中介；勿过度因果化。

### 7.3 调节效应分析（D×M→Y）
- **做什么**：检验调节变量 M 是否强化/弱化 D 对 Y 的效应。与第 6 步异质性区分：调节变量须有理论上的“放大/缓冲”机制，避免用同一分组变量既做异质性又做机制。
- **方法/模型**（选 1 种）：①交互项回归（推荐）：`reghdfe {Y} c.{D} c.{M} c.{D}#c.{M} {X}, absorb({FE}) vce(cluster {聚类})`——连续调节变量先中心化；虚拟调节用 i.{M} 与 c.{D}#i.{M}；②分组回归 + suest；③简单斜率（可选）：`margins, dydx({D}) at({M}=(-1sd 均值 +1sd))`，必要时画简单斜率图。
- **估计方程**：Y = β0 + β1·D + β2·M + β3·(D×M) + γX + μ_i + λ_t + ε。关键参数 β3。
- **要输出**：β3 系数、SE、显著性、N；主效应 D 与 M 系数；（分组回归）各组系数与组间差异检验；（可选）简单斜率数值或图。
- **怎么读**：β3 显著为正 → 强化；显著为负 → 弱化；不显著 → 无调节。加入交互项后 D 的主效应解释为“M=0 时的效应”，中心化后才有“平均效应”含义，不必过度解读主效应显著性。

## 第 8 步：进一步讨论/扩展（可选）
- 长期/动态效应与滞后结构（滞后 1~3 期，或事件研究各期系数）。
- 溢出/间接效应（邻近地区、上下游）。
- 经济后果与成本收益（系数换算为经济规模/政策成本）。
- 分解（Oaxaca–Blinder、Shapley、方差分解）。
- 异质性×机制交互（机制变量是否在不同组别表现不同）。
- **要输出**：一张表或图（事件研究建议画系数图），报 D 系数、SE、显著性、N。
